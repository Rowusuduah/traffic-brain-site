# Workflow — Project Close-Out
1. Deliverables archive: final PDFs + native files + submittal record (what/when/to whom) in 05.
2. Comment matrices: all cycles, closed, filed — the next similar project's crystal ball.
3. [[T - Lessons Learned]]: 3 minimum (technical · process · client/agency); rules encoded into checklists.
4. Reusables harvested: accepted methodology memo → pattern note · workbook → template · new agency intel → `03 Agencies` note.
5. [[Experience Tracker for PE-PTOE]] entry WHILE FRESH: your role, engineering decisions, PE supervisor, dates.
6. Project note status → closed; 60-second future-self summary at top ("what this was, where the gold is").
