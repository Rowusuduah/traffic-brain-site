# Standards Update Tracker

Standards move; your notes must move with them. Quarterly (Jan/Apr/Jul/Oct), check each and update `last-checked` in the reference note.

| Item | Cycle | Watch for | Note |
|---|---|---|---|
| FDOT Design Manual (FDM) | Annual (Jan) | New edition + errata | [[FDOT Design Manual (FDM)]] |
| FDOT Standard Plans | Annual (FY, ~Jul adoption) | New FY set + IDS/interim revisions | [[FDOT Standard Plans]] |
| FDOT Standard Specifications | ~Annual + supplemental | Workbook updates | [[FDOT Standard Specifications]] |
| FDOT TEM | Rolling revisions | Chapter revision dates | [[FDOT Traffic Engineering Manual (TEM)]] |
| Florida Greenbook | Multi-year | New edition adoption by rule | [[Florida Greenbook]] |
| MUTCD + FL supplement | Multi-year | State adoption status of 11th Ed. | [[MUTCD]] |
| Florida Statutes Ch. 316 / 61G15 FAC | Annual session | Speed, TTC, licensure changes | [[Speed Limits in Florida]] |
| Local TIA/parking/calming guidelines | Ad hoc | Agency site "last updated" | `03 Agencies` notes |
| ITE Trip Gen / Parking Gen, ULI SP | New editions | Which edition the agency accepts | [[ITE Trip Generation]] etc. |
| Software versions (Synchro, ORD, FDOTConnect) | Vendor | Firm's standard version vs latest | [[MOC - Software]] |

Rule: when a standard updates, search the vault for its tag, fix affected notes, and add a `LESSON:` if the change would have bitten a live project.
