# Monthly Technical Growth Review (last Friday, 45 min)

1. **[[Skill Tracker]]**: move skills between Know / Learning / Need. Be honest — "watched a video" ≠ Know. "Did it on a project unassisted" = Know.
2. **Gap pick**: choose ONE skill for next month. Define the artifact that proves it (e.g., "coded a coordinated Synchro network and my QA/QC found my own errors").
3. **[[Standards Update Tracker]]**: quarterly months (Jan/Apr/Jul/Oct) — run the re-check list (FDM release, Standard Plans FY, statute changes, agency guideline updates).
4. **Lessons roll-up**: reread the month's lessons; any pattern (e.g., "I keep missing PHF") → make it a personal QA/QC checklist item.
5. **Career ledger**: add month's project experience to [[Experience Tracker for PE-PTOE]] while it's fresh — future-you filling a PE application will be grateful.
6. **Ask yourself**: What did I do this month a senior didn't have to redo? What still comes back with heavy redlines? Next month, attack the second list.
