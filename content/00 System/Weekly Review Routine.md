title: "Weekly Review Routine (Friday, 20–30 min, calendar-blocked)"
---
1. **Sweep** this week's daily notes + inbox.
2. **Promote**: each LEARN/FIX worth keeping → real note from the right template (90 sec each; a 5-line note beats no note). Link it from its domain MOC.
3. **Questions**: move all `Q:` items → your questions-for-seniors list; batch-ask the top 3 on Monday.
4. **Lessons**: any review comment or mistake → one line in the active project's Lessons Learned section (see [[Lessons Learned System]]).
5. **Timesheet sanity**: hours match reality? Utilization on track? (see [[Workflow - New Task Intake]] → timesheet discipline).
6. **Next week**: pick the 1–3 tasks that matter most; note any deliverable dates in project notes.
7. **Inbox zero**: whatever's left in Inbox gets promoted or deleted. Never let it roll two weeks.

Output check: this week produced ≥3 permanent notes and ≥1 lesson. If zero, capture is broken — fix the trigger habit, not the system.
