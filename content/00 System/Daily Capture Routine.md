---
The whole system dies if capture has friction. Standard: **open daily note → type one line → back to work in under 15 seconds.**

## Capture triggers — write it down the moment you:
- Get corrected by a senior engineer (verbatim what they said)
- Find a number/threshold you had to look up (turn lane length, stall width, Y+AR formula...)
- Hit a software error and solve it
- Hear an acronym you don't know
- Make an assumption in an analysis
- Receive a review comment on your work
- Discover a useful link, tool, or example project

## Format (in today's daily note)
```
- LEARN: [what] — [where it came from]
- Q: [question] → #status/ask-pe
- FIX: [problem] → [solution]
- ASSUME: [project] — [assumption + basis]
- LINK: [url] — [what it is] #src/xxx
```
Don't file, don't polish, don't make real notes now. Friday does that. See [[Weekly Review Routine]].
