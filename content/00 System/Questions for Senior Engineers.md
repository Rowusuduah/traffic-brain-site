# Questions for Senior Engineers

Batch questions; don't drip them. Before asking, each question must pass the **3-source test**: I checked (1) a reference note / manual, (2) a past project example, (3) one honest search — and here's what I found. Then the question becomes *"I think X because Y — am I reading this right?"* instead of *"what do I do?"* That's the difference between a junior who's learning and one who's outsourcing.

## Format
- [ ] **Q:** … **My best answer:** … **Checked:** FDM 212 / old SR-XX project / forum thread. **Asked:** [name, date] **Answer:** … → promoted to [[note]]
