# Lessons Learned System

Three levels, all cheap:
1. **In the moment** — one `LESSON:` line in the daily note.
2. **Per project** — Lessons section inside every `PRJ -` note (template built in). Filled at review comments and at close-out ([[T - Lessons Learned]]).
3. **Patterns** — monthly review promotes repeated lessons into (a) a personal QA/QC checklist item, or (b) a permanent concept note.

## Lesson format (make it reusable, not confessional)
> **Situation → What went wrong/right → Root cause → Rule I'll follow → Where encoded** ([[checklist]]/[[note]])

A lesson that doesn't change a checklist or a note isn't captured yet — it's just a memory, and memories fade by the next deadline.
