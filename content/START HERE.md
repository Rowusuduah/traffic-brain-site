# START HERE

This vault is your **Traffic Engineering Brain** — a working operating system for going from entry-level EIT to a strong Florida traffic engineer. It is deliberately ~20% pre-filled and ~80% scaffolded. Notes you write yourself are the ones you retrieve under pressure; the system's job is to make writing them take 90 seconds, not to hand you a textbook you'll never reread.

## Setup (15 minutes, once)
1. Open Obsidian → **Open folder as vault** → select this folder.
2. Settings → Core plugins → enable **Templates**, **Daily notes**, **Backlinks**, **Outgoing links**.
3. Settings → Templates → set folder to `01 Templates`. Settings → Daily notes → set folder to `21 Daily`, template to `T - Daily Log`.
4. (Recommended) Community plugins → install **Dataview**. Dashboards in [[00 Home]] use it; everything still works without it via manual links.
5. Pin [[00 Home]] as your first tab.

## The operating loop
- **Capture** (all day): anything worth keeping → [[Inbox]] or today's daily note. Don't file, don't format. See [[Daily Capture Routine]].
- **Friday, 20 min**: [[Weekly Review Routine]] — empty inbox into real notes, log lessons, queue questions for seniors.
- **Last Friday of month, 45 min**: [[Monthly Technical Growth Review]] — update [[Skill Tracker]], pick next month's focus.
- **Per project**: create a folder in `20 Projects` from [[T - Project]]; close it out with [[T - Lessons Learned]].

## Rules of the vault
1. **Verify before you rely.** Anything tagged `#status/verify` (statute numbers, manual editions, URLs) gets checked against the current official source before it touches real work. Log the date in the note's `last-checked` field.
2. **Official sources decide; everything else teaches.** Source classes 1–2 (official/professional) for engineering judgment; classes 3–7 (tutorials, examples, Reddit, GitHub, opinion) for learning only. See [[Workflow - Research and Source Vetting]].
3. **An EIT does not sign, seal, or make final engineering decisions.** When in doubt → [[EIT Boundaries Ethics and Liability]] → ask the PE.
4. Links rot. Every reference note has a `last-checked` date. [[Standards Update Tracker]] tells you what to re-check quarterly.
