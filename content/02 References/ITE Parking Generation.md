**What:** observed peak parking demand rates by land use, setting (urban/suburban), and time.
**Why:** the standalone-demand leg of the parking triad (code vs ITE vs ULI vs observed); justifies reductions when code overshoots.
**When:** parking studies, variance support, checking a code ratio against data.
**Example questions:** 85th-percentile vs average rate — which does the agency accept? weekday vs weekend peak for this LU?
