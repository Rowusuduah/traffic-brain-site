**What:** FDOT's classification of roadways by land-use context, C1 through C6 (C1 Natural → C2 Rural / C2T Rural Town → C3R/C3C Suburban → C4 Urban General → C5 Urban Center → C6 Urban Core `#status/verify` subcategory labels against the guide). The [Context Classification Guide PDF](https://fdotwww.blob.core.windows.net/sitefinity/docs/default-source/roadway/completestreets/files/fdot-context-classification.pdf) has the definitions plus the primary/secondary measures used to assign a class.
**Why:** context classification + functional classification together drive FDM design criteria and **target speed** — lane widths, design speed, and complete-streets features on the SHS all key off it. The [[Speed Limits in Florida]] and FDM notes both silently depend on this.
**When:** scoping any SHS design or study — pull the corridor's class first; challenging a criteria choice ("why 11-ft lanes here?"); framing calming/complete-streets asks in FDOT language.

> [!tip] Statewide **preliminary** context classification GIS layer lives on the FDOT Open Data Hub: https://gis-fdot.opendata.arcgis.com/datasets/preliminary-context-classification-tda — look up any corridor in seconds before scoping.

> [!warning] The GIS layer is *preliminary* — the class is verified/adjusted during project development with the district. Don't lock design criteria to an unconfirmed context class.
