FDOT's governing design criteria and plans-production requirements for the State Highway System.

> [!warning]
> Replaced the old **Plans Preparation Manual (PPM) in 2018** — old plans/reports still cite PPM; map citations forward.

**Why it matters:** on any FDOT project, this is the answer key. Context classification (C1–C6T) drives design speed, lane/shoulder widths, and target speeds — learn Ch. 200-series cold.

**When:**
- design criteria checks
- turn lanes
- sight distance
- ped/bike facilities
- plans content
- exceptions/variations process

**Example questions:**
- min turn-lane length at 45 mph?
- required border width?
- when is a design variation vs exception needed?
- what does context class C3C imply?
