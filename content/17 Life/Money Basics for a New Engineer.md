# Money Basics for a New Engineer (educational, not financial advice — verify numbers/limits for the current year)
**Order of operations (standard personal-finance consensus):** 1) starter emergency fund ($1–2k) → 2) employer 401(k) **to the full match** (declining a match is declining salary) → 3) kill high-interest debt → 4) emergency fund to 3–6 months expenses (HYSA) → 5) max tax-advantaged space as able (Roth IRA / more 401(k) / **HSA if on an HDHP** — triple tax advantage) → 6) taxable investing. Default investment posture most professionals use: broad low-cost index funds / target-date fund; the win is savings RATE + time, not picking.
**Benefits election week (do once, well):** health plan math (premium vs deductible vs your actual usage; HSA eligibility) · disability insurance — **long-term disability is the underrated one for an engineer whose asset is earning power** · employer life if dependents · FSA/commuter as applicable.
**Budget:** one boring system (50/30/20 or zero-based), automated transfers on payday; review monthly in 10 minutes. Grad-stipend habits + engineer salary = a savings-rate superpower if lifestyle inflation waits a year.
**Do:** credit score hygiene (autopay everything) · beneficiaries set · renters insurance.
