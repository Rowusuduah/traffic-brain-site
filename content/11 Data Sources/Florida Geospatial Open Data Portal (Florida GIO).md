**What:** the Florida Geographic Information Office's cross-agency open data portal — authoritative statewide layers beyond FDOT's holdings: imagery, elevation, boundaries, addresses, and whatever other state agencies publish.
**Why:** one search across all state agencies' published geodata instead of guessing which agency owns the layer.
**When:** the layer isn't on the FDOT hub or FGDL — think imagery/elevation for exhibits, address points, jurisdictional boundaries.

No login. As with any aggregator, open the item page and note the owning agency and vintage before you put it on a stamped figure.

> [!tip]
> Search order for Florida layers: [[FDOT Open Data Hub]] (transportation) → county GeoHub (local assets) → here or [[Florida Geographic Data Library (FGDL)]] (everything else / historical).
