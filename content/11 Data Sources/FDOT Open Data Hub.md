**What:** FDOT's ArcGIS open data portal — downloadable shapefiles/GeoJSON and live REST feature services for AADT, Roadway Characteristics Inventory (RCI), functional classification, crashes, bridges, context classification, and much more.
**Why:** the standard free source for mapping any Florida corridor study; every study figure starts here.
**When:** building base maps, corridor inventory before a field review, joining AADT or functional class to your own layers.

No login. Gotchas: read the layer metadata before trusting it — vintage and coverage vary, and RCI-derived layers describe the State Highway System only (field-verify anything older than the current cycle). City/county assets live on the local GeoHubs, not here.

> [!tip]
> You rarely need to download: paste the layer's REST service URL straight into QGIS/ArcGIS and it stays current. Workflow notes in [[GIS and Google Earth]].
